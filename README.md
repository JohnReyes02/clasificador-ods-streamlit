# Clasificador de textos por ODS

Aplicación desarrollada con Streamlit para clasificar textos en español según los Objetivos de Desarrollo Sostenible.

El modelo utiliza un pipeline de procesamiento compuesto por TF-IDF, reducción dimensional mediante SVD y regresión logística.

## Ejecutar localmente

```bash
python -m pip install -r microproyectos/microproyecto-2/requirements.txt
python -m streamlit run microproyectos/microproyecto-2/streamlit_app.py
```
